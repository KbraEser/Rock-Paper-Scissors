# Taş Kağıt Makas Oyunu 🎮

Bu proje, klasik Taş Kağıt Makas oyununun interaktif bir web uygulamasıdır.

## Tanıtım Videosu 🎥

Oyunun nasıl oynandığını görmek için [YouTube videosunu](https://youtu.be/qXz1E-N-mNY) izleyebilirsiniz.

## Özellikler

- Kullanıcı dostu arayüz
- Taş, kağıt ve makas seçenekleri için görsel ikonlar
- Anlık skor takibi
- Otomatik oyun modu
- Skor sıfırlama özelliği
- Yerel depolama ile skor kaydetme

## Nasıl Oynanır?

1. Taş, kağıt veya makas butonlarından birini seçin
2. Bilgisayar otomatik olarak kendi seçimini yapacaktır
3. Kazanan ekranda gösterilecek ve skor güncellenecektir
4. İsterseniz "Auto Play" butonu ile otomatik oyun modunu başlatabilirsiniz
5. Skorları sıfırlamak için "Reset Score" butonunu kullanabilirsiniz

## Teknolojiler

- HTML
- CSS
- JavaScript
- Local Storage API

## Kurulum

1. Projeyi bilgisayarınıza indirin
2. VS Code veya Cursor IDE'sinde Live Server eklentisini yükleyin
3. HTML dosyasına sağ tıklayıp "Open with Live Server" seçeneğini seçin
4. Tarayıcınızda oyun otomatik olarak açılacaktır
